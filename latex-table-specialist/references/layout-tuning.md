# Layout Tuning

这份参考解决的是“表格已经基本对了，但还不够漂亮”的问题。

## 一眼不好看的常见原因

- 线太多
- 数字没有对齐
- 表头太长太啰嗦
- 单位在每个单元格里重复出现
- 列距太宽或太挤
- 长文本被硬塞成一行
- 没有分组，读者看不出结构

## 优化顺序

1. 先减线
2. 再重排列顺序
3. 再统一表头措辞
4. 再做数字对齐
5. 再处理长文本列
6. 最后微调间距和字号

## 推荐手段

### 收紧左右边距

```latex
\begin{tabular}{@{}lrr@{}}
```

适合：表格本身不宽，但左右看起来发虚。

### 微调列间距

```latex
\setlength{\tabcolsep}{5pt}
```

适合：表格略宽或列之间空得不均匀。

### 轻微调整行距

```latex
\renewcommand{\arraystretch}{1.08}
```

适合：表格太“板”，呼吸感不够。

### 让长文本列换行

```latex
\begin{tabularx}{\linewidth}{lXr}
```

适合：解释性列、方法描述列、消融设置列。

### 数字按小数点对齐

```latex
\begin{tabular}{lS[table-format=2.2]}
```

适合：实验结果、误差、时间、参数量。

### 用分组表头建立层次

```latex
\multicolumn{2}{c}{Validation}
\cmidrule(lr){2-3}
```

适合：同类指标、不同数据集、不同拆分。

## 何时缩字号

只有当前面的结构优化做完仍然过宽时，才考虑：

```latex
\small
```

默认不建议：

- 一上来就 `\scriptsize`
- 为了塞进页面牺牲可读性

## 何时拆表

出现下面情况时，拆表通常比硬压更好：

- 列太多且没有自然分组
- 文本说明和数值比较混在一起
- 同一张表同时承担“定义说明”和“主结果比较”两个任务

## 何时换环境

- 还是短表：留在 `tabular`
- 宽度是主要问题：切 `tabularx`
- 需要表注：加 `threeparttable`
- 超过一页：切 `longtable`
- 项目已采用现代语法：考虑 `tblr`
